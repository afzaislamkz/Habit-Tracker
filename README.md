# 🌱 Habit Tracker

A simple and clean **Habit Tracker Web App** built with **HTML, CSS, and JavaScript**.

It helps you track your daily habits, monitor your progress, build streaks, and stay consistent with your goals.

## ✨ Features

* ✅ Add new habits
* ☑️ Mark habits as completed
* 📅 Track habits by month
* 📊 Monthly progress percentage
* 🔥 Best streak tracking
* 📈 Habit insights
* 💧 Water reminder with 15-minute timer
* 🌙 Dark / Night Mode
* ☀️ Light Mode
* 🗑️ Delete individual habits
* 🧹 Clear All Data option
* 💾 Data saved automatically using Local Storage
* 📱 Responsive design for mobile and desktop

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage
* Font Awesome / Emojis

## 🚀 How to Use

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start adding and tracking your habits.

No server or database is required.

## 💾 Data Storage

The Habit Tracker uses **Browser Local Storage** to save your habit data.

Your data remains available when you close and reopen the browser.

The **Clear All Data** button removes habit and water-tracking data while keeping your theme preference.

## 🌙 Theme Mode

The application supports:

* 🌙 Night Mode
* ☀️ Light Mode

Your selected theme is also saved in Local Storage.

## 💧 Water Reminder

The built-in water reminder provides a **15-minute countdown**.

You can:

* Start the reminder
* Stop the reminder
* Mark water as consumed
* Track your water reminder status

## 📊 Progress Tracking

The dashboard displays:

* Total Habits
* Today's Completed Habits
* Monthly Progress
* Best Streak

This makes it easier to see your consistency over time.
